================================================================================
           J3A Discord Profile - Discord Rich Presence Controller
================================================================================

ขอขอบคุณที่เลือกใช้งาน J3A Discord Profile!
โปรแกรมสำหรับปรับแต่งสถานะ Discord Rich Presence แสดงรายละเอียดกิจกรรม, รูปภาพ,
เวลานับเดินหน้า และปุ่มกดลิงก์ (Buttons) บนโปรไฟล์ Discord ของคุณแบบมืออาชีพ

--------------------------------------------------------------------------------
1. สิ่งที่ต้องมีก่อนเริ่มใช้งาน
--------------------------------------------------------------------------------
- โปรแกรม Discord Desktop (เปิดล็อกอินไว้บนเครื่องคอมพิวเตอร์ของคุณ)
  * หมายเหตุ: ต้องเป็น Discord Desktop เท่านั้น ไม่สามารถใช้ผ่านเว็บบราวเซอร์ได้
- การเปิดตั้งค่าใน Discord:
  ไปที่ User Settings (ฟันเฟือง) -> Activity Privacy (ความเป็นส่วนตัวของกิจกรรม)
  -> เปิด "Display current activity as a status message" (แชร์กิจกรรมปัจจุบันเป็นสถานะ)

--------------------------------------------------------------------------------
2. วิธีเริ่มต้นใช้งาน
--------------------------------------------------------------------------------
ขั้นตอนที่ 1: เปิดโปรแกรมและยืนยันสิทธิ์ License Key (ครั้งแรกเท่านั้น)
1. ดับเบิ้ลคลิกเปิด "J3ADiscordProfile.exe"
2. หน้าต่าง "เปิดใช้งานโปรแกรม (License Activation)" จะแสดงขึ้นมา
3. กรอก License Key ที่คุณได้รับจากการสั่งซื้อ แล้วกด "🚀 ยืนยันและเปิดใช้งาน"
   (ระบบจะผูกสิทธิ์ 1 สิทธิ์ต่อ 1 เครื่องคอมพิวเตอร์ผ่านรหัสอุปกรณ์อัตโนมัติ)

ขั้นตอนที่ 2: สร้าง Application ใน Discord Developer Portal
1. เปิดเว็บ https://discord.com/developers/applications และล็อกอิน
2. กดปุ่ม "New Application" (มุมขวาบน)
3. ตั้งชื่อแอป (ชื่อนี้คือสิ่งที่จะขึ้นเป็นคำว่า Playing หรือ กำลังเล่น บนโปรไฟล์)
4. ไปที่เมนูซ้าย "General Information" แล้วกดคัดลอก "Application ID" (ตัวเลข 17-20 หลัก)

ขั้นตอนที่ 3: ตั้งค่าและเริ่มใช้งาน
1. วาง Application ID ในช่อง "Application ID"
2. กรอกข้อความสถานะตามต้องการ:
   - Details: ข้อความบรรทัดบน (เช่น กำลังเล่น, เซิร์ฟเวอร์เปิดแล้ว)
   - State: ข้อความบรรทัดล่าง (เช่น ชิลๆ, Open Beta)
   - Start time: เปิด/ปิดการนับเวลาเดินหน้า สามารถเลือกวันเริ่มนับย้อนหลังได้
   - Buttons: ใส่ปุ่มกดได้สูงสุด 2 ปุ่ม (เช่น Join Discord, Website) พร้อมใส่ลิงก์ปลายทาง
3. กดปุ่ม "▶ เริ่มใช้งาน"
   สถานะจะเปลี่ยนเป็น "ออนไลน์" และข้อความจะขึ้นบนโปรไฟล์ Discord ของคุณทันที!

--------------------------------------------------------------------------------
3. ข้อควรรู้และคำถามที่พบบ่อย (FAQ)
--------------------------------------------------------------------------------
Q: ทำไมมองไม่เห็นปุ่มบนโปรไฟล์ตัวเอง?
A: เป็นระบบความปลอดภัยของ Discord เองที่ "จะไม่แสดงปุ่มบนโปรไฟล์ของตัวเราเอง"
   แต่เพื่อนทุกคนและคนอื่นใน Discord ที่กดคลิกดูโปรไฟล์ของคุณจะเห็นปุ่มทั้ง 2 ปุ่ม
   และสามารถคลิกลิงก์ได้ตามปกติ 100% ครับ (ลองให้เพื่อนช่วยเช็คได้เลย)

Q: ต้องการเปลี่ยนข้อความระหว่างเปิดใช้งานอยู่ ต้องทำอย่างไร?
A: เมื่อแก้ไขข้อความในช่องต่างๆ ให้กดปุ่ม "↻ อัปเดตสถานะ" เพื่อส่งข้อมูลใหม่ไปยัง Discord ทันที

Q: วิธีใส่รูปภาพ Large Image / Small Image ทำอย่างไร?
A: ใน Developer Portal เมนูซ้ายเลือก "Rich Presence" -> "Art Assets"
   -> อัปโหลดรูปภาพขนาด 1024x1024 และตั้งชื่อ Key (เช่น logo)
   -> นำชื่อ Key นั้นมาใส่ในช่อง Large Image Key ในโปรแกรม

Q: ย้ายเครื่องคอมพิวเตอร์หรือลง Windows ใหม่ทำอย่างไร?
A: สามารถกดที่แถบ "สิทธิ์: Active" มุมขวาบน แล้วกด "ถอนการผูกคีย์" หรือติดต่อแอดมินเพื่อรีเซ็ตสิทธิ์ให้ครับ

--------------------------------------------------------------------------------
4. นโยบายความเป็นส่วนตัวและสิทธิ์การใช้งาน
--------------------------------------------------------------------------------
• 1 License Key สำหรับใช้งานบนคอมพิวเตอร์ 1 เครื่อง
• โปรแกรมจะบันทึกเฉพาะรหัสเฉพาะของอุปกรณ์ (Hardware ID) เพื่อตรวจสอบสิทธิ์เท่านั้น
  ไม่มีการเข้าถึงหรือจัดเก็บข้อมูลส่วนตัวใดๆ ในเครื่องคอมพิวเตอร์ของผู้ใช้ทั้งสิ้น
